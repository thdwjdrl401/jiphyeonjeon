# harness-check

기능/변경에 계약 테스트·린트가 필요한지 판단하고 근거를 출력한다. (Cursor 어댑터 — 알맹이는 공통 문서)

1. `docs/harness/POLICY.md`의 판단 기준과 `docs/CONTRACT.md`의 공유 계약을 읽는다.
2. 대상이 어느 마일스톤(Sub Ⅰ/Ⅱ/Ⅲ)이고 **FE/BE 공유 경계를 넘는지**(필드명·상태코드 계약) 판단한다.
3. 결론을 **계약 테스트 필요 / 린트로 충분 / 불필요** 중 하나로 명시하고 근거를 댄다.
4. 자물쇠가 필요하면 `docs/harness/ENFORCEMENT.md`의 어느 절차로 켜는지 안내한다.
5. 유의미한 결정이면 `docs/decisions/0000-template.md` 형식의 ADR 초안(다음 번호)을 출력한다.

코드를 수정하지 말고 판단·근거·다음 행동만 보고하라.
