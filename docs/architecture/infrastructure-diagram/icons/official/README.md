# Official icon sources

The self-contained infrastructure SVG is built from these vendored vector marks.

- `aws/amazon-ec2.svg`: AWS Architecture Icons package dated 2026-04-30, downloaded from the [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) page.
- `simple-icons/*.svg`: Simple Icons 16.28.0 brand marks. The bundled `SIMPLE_ICONS_LICENSE.md` is CC0-1.0; individual trademarks remain owned by their respective brands.

Run `python3 docs/architecture/infrastructure-diagram/tools/build_infrastructure_official.py` after changing the layout or icon set.
