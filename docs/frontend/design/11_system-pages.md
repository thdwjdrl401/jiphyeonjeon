# 시스템 페이지 — 접근 불가 · 찾을 수 없음

> 원본: [../components/SYSTEM_PAGES.md](../components/SYSTEM_PAGES.md) · 로드맵: [00_ROADMAP.md](00_ROADMAP.md)

| 화면 | 라우트 | 레이아웃 | 접근 |
|---|---|---|---|
| 접근 불가 | `/forbidden` | `SystemLayout` | 전체 |
| 찾을 수 없음 | `*` | `SystemLayout` | 전체 |

## 공통 화면 구성
```text
SystemMessagePanel
├─ SystemStatusIcon
├─ SystemStatusTitle
├─ SystemStatusDescription
├─ SystemPrimaryAction       — 원인에 맞는 대표 복구 행동 1개
├─ SystemSecondaryActions    — 웰컴·내 커리큘럼·커리큘럼 목록 등 보조 이동
└─ SupportReference          필요한 경우만 — 비민감 추적 식별자
```

브랜드 링크 + 단순 본문만 있는 최소 레이아웃. 오류 코드보다 "왜 막혔는지"와 "다음에 뭘 하면 되는지"를 우선한다. 서버 오류 세부·내부 식별자·보호 리소스 존재 여부는 노출하지 않는다.

---

## 1. 접근 불가 (`/forbidden`)
인증된 사용자가 권한이 없을 때(403) 표시. 비로그인(401)은 원칙적으로 이 화면 대신 로그인으로 보낸다.

### 원인별 복구 행동
| 원인 | 대표 행동 | 보조 행동 |
|---|---|---|
| 비로그인(로그인 리다이렉트 실패 등 예외 상황) | 로그인 후 원래 목적지 복귀 | 웰컴 |
| 학생·미수강 | 커리큘럼 상세에서 수강 확인 | 내 커리큘럼 |
| 수강 승인 대기 | 커리큘럼 상세에서 상태 확인 | 내 커리큘럼 |
| 강사 전용 기능 접근 | 내 커리큘럼 | 커리큘럼 목록 |
| 다른 강사의 관리 리소스 | 내 커리큘럼 | 웰컴 |
| 권한 회수·수강 종료 | 커리큘럼 상세 | 내 커리큘럼 |

다른 강사의 커리큘럼 이름·수강생·자료 같은 보호 정보는 절대 노출하지 않는다.

## 2. 찾을 수 없음 (`*`)
라우트가 존재하지 않거나 요청한 리소스(커리큘럼/섹션/레슨/라이브 세션)를 찾을 수 없을 때 표시. 잘못된 URL과 "삭제됨/비공개/권한 없음"을 굳이 구분하지 않고 같은 일반 문구로 처리해도 된다(보호 리소스 존재 여부 비노출).

### 인증 상태별 복구 행동
| 사용자 | 대표 행동 | 보조 행동 |
|---|---|---|
| 비로그인 | 웰컴 | 커리큘럼 목록 |
| 학생 | 내 커리큘럼 | 커리큘럼 목록 |
| 강사 | 내 커리큘럼 | 커리큘럼 목록 |

검색 입력은 넣지 않고 커리큘럼 목록으로만 연결한다. 자동 리다이렉트는 하지 않는다(사용자가 직접 버튼을 눌러 이동).

## 상태
- 정상 표시: 제목·설명·대표 행동
- 인증 확인 중: 짧은 로딩 후 역할별 복구 행동 표시(잘못된 역할별 행동을 먼저 보여주지 않음)
- 복구 행동 실패: 같은 화면에서 재시도, 5xx/네트워크 장애를 권한 없음·찾을 수 없음으로 오인 표시하지 않음
