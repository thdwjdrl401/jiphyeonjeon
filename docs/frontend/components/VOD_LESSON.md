# LiveClass AI — VOD 레슨 컴포넌트

> 컴포넌트 원칙: [README.md](README.md) · 공통 레이아웃: [COMMON.md](COMMON.md) · 라이브 레슨: [LIVE_LESSON.md](LIVE_LESSON.md) · 페이지 기준: [PAGES.md](../PAGES.md)

## 1. 목적

VOD 레슨은 종료된 라이브 레슨의 Egress HLS 녹화를 재생하고, 교정 자막·채팅 리플레이·PPTX 및 발화 근거·개인 AI Q&A·북마크·퀴즈를 같은 시간축에서 제공하는 학습 페이지다.

- 수강생: 마지막 시점부터 학습을 이어가고, 영상 맥락에 맞는 학습 기능 이용
- 강사: HLS를 미리보기하면서 AI 원본 후보를 검수·수정·게시하고 질문·학습 현황 확인

라이브 레슨과 `LessonLayout` 및 일부 학습 feature를 공유하지만, HLS 탐색과 저장된 데이터 재생이 중심이므로 별도 라우트와 페이지를 사용한다.

## 2. 확정 원칙

> **UI 목업 기준(2026-07-23)**: 학생·강사 다시보기의 기본 학습 사이드바는 라이브와 같은 `채팅·질문 / 실시간 노트 / AI 질문 / 핵심 용어` 네 탭을 사용한다. 라이브에서 생성된 구간 요약 블록과 검수 용어를 읽기 형태로 재사용하며, 역할별 검수·통계·퀴즈의 최종 위치는 후속 논의한다. 상세 결정은 [ADR-0019](../../decisions/yoongwanghyeok/0019-unified-learning-sidebar-and-caption-dock-preview.md)를 따른다.

- VOD는 라이브 Egress가 생성한 HLS만 사용하며 영상 업로드는 제공하지 않음
- 새 정상 녹화는 `videoAssetStatus=READY`와 `replayStatus=PUBLISHED`를 같은 webhook 트랜잭션에서
  확정해 수강생 영상을 자동 공개
- 기존 `READY + DRAFT/READY_FOR_REVIEW`와 `WITHDRAWN`은 자동 공개하지 않고 수동 게시·재게시
- 수강생 영상 재생은 `replayStatus=PUBLISHED`일 때만 허용
- 영상과 자막·용어·요약·퀴즈 준비 상태를 분리
- AI 원본과 후보는 자동 게시하지 않고 강사 승인 후 게시본 생성
- AI 원본은 보존하고 게시본만 버전으로 관리
- 검수 전 후보는 강사에게만 표시하고 수강생에게는 승인된 게시본만 표시
- 영상은 AI 게시본 없이도 별도로 게시 가능
- 채팅 리플레이는 가명·시간 동기화·읽기 전용
- 개인 AI Q&A 기록은 사용자 본인에게만 공개하되 질문 원문과 시점은 강사용 통계에 익명 반영
- 학습 진행률은 자동 저장하고 서버가 90% 시청을 완료 기준으로 판단
- 퀴즈는 강사가 후보를 검수·게시한 뒤 별도 패널에서 응시
- 강사용 질문 핀은 라이브와 같은 구조 사용

## 3. 게시본과 버전 원칙

```text
AI 원본(ai)
   └─ AI 후보(ai, 강사만 확인)
          └─ 강사 검수·승인 게시본(core v1+) ── 수강생 노출
```

- AI 원본은 검수 과정에서 덮어쓰지 않음
- 수강생은 현재 활성화된 게시본만 사용
- 강사는 AI 원본 후보·검수 초안·현재 게시본을 구분해서 확인
- 검수 결과를 저장하는 것과 수강생 게시본을 교체하는 행동을 구분
- 게시본 교체 후 새 조회부터 최신 버전을 사용
- 진행 중인 AI 답변이나 퀴즈 응시는 시작할 때의 버전을 기준으로 완료

퀴즈도 승인 후 첫 게시본을 만들고 같은 방식으로 버전 관리한다.

- AI 퀴즈 후보는 수강생에게 노출하지 않음
- 강사가 처음 승인·게시한 퀴즈를 `v1`로 간주
- 이후 강사 검수 결과를 새 버전으로 게시
- 기존 응시 결과는 응시 당시 퀴즈 버전에 연결해 보존
- 새 응시는 현재 게시 버전을 사용
- 새 버전이 게시되면 기존 응시자에게 재응시 가능 상태를 안내
- 강사 검수로 기존 점수와 응시 기록을 자동 삭제하지 않음

## 6. 접근 권한과 표시 조건

### 6.1 공통 접근

- 해당 커리큘럼 강사 또는 수강생만 접근
- 비로그인·미수강 학생·다른 커리큘럼 강사는 라우트 진입 단계에서 차단
- 강사는 `videoAssetStatus=READY`일 때 VOD 미리보기·검수 페이지 진입
- 수강생은 `videoAssetStatus=READY`와 `replayStatus=PUBLISHED`를 모두 만족할 때 진입
- `PROCESSING`이면 레슨 상세에서 준비 중 상태 표시
- `FAILED`이면 실패 안내와 복구 동선 제공
- 권한과 재생 URL 발급은 서버에서도 검증

### 6.2 수강생

- 현재 활성화된 게시본만 확인
- 강사 검수 패널과 질문 원문 통계에 접근할 수 없음
- 자신의 진행률·북마크·퀴즈 결과·AI Q&A 기록만 확인

### 6.3 강사

- 수강생에게 보이는 현재 게시본 확인
- AI 원본 후보·검수 초안·현재 게시본 비교
- 자막·용어·챕터·퀴즈 검수와 새 게시본 게시
- 익명 질문 핀과 집계 학습 현황 확인
- 개인별 AI 질문 작성자나 개인 질문 기록 전체는 확인하지 않음

## 7. VOD 공개와 AI 콘텐츠 상태

영상 처리, replay 공개, AI 콘텐츠 게시 상태는 독립적으로 관리한다.

| 영상 상태 | replay 상태 | AI 콘텐츠 상태 | 수강생 화면 |
|---|---|---|---|
| 자산 `FINALIZING/VERIFYING` | 무관 | 무관 | 레슨 상세에서 준비 중 안내 |
| 자산 `READY` | `DRAFT/READY_FOR_REVIEW` | 무관 | 기존 미게시 자산: 게시 대기 안내, 재생 불가 |
| 자산 `READY` | `PUBLISHED` | AI 처리 중·미게시 | 영상 재생, 해당 AI 영역은 준비 중 또는 미제공 |
| 자산 `READY` | `PUBLISHED` | 일부 게시 완료 | 영상과 승인·게시된 영역만 표시 |
| 자산 `READY` | `PUBLISHED` | 일부 AI 실패 | 영상과 기존 게시 기능 유지, 실패 영역만 안내 |
| 자산 `READY` | `WITHDRAWN` | 무관 | 공개 중단 안내, 신규 재생 불가 |

자막·용어·챕터·퀴즈는 서로 다른 시점에 준비되거나 검수될 수 있으므로 하나의 전역 AI 상태로 모든 영역을 막지 않는다.

## 8. HLS 재생

### 8.1 초기 재생

- Spring에서 재생 URL과 재생 가능 여부 확인
- nginx를 통해 Egress HLS 재생
- 저장된 마지막 위치가 있으면 이어보기 제안
- 사용자가 처음부터 재생을 선택할 수 있음
- 마지막 위치가 영상 끝에 가까우면 처음부터 재생을 기본 제안

### 8.2 기본 제어

- 재생·일시정지
- 구간 탐색
- 음량·음소거
- 재생 속도
- 전체화면
- 현재 시각·전체 길이
- 게시 자막 표시·숨김

화질 선택과 PIP는 HLS 구성과 브라우저 지원을 확인한 뒤 추가한다.

### 8.3 시점 이동

다음 행동은 모두 같은 플레이어 시점 변경으로 연결한다.

- 자막 검색 결과 선택
- 챕터 선택
- AI 답변 근거 선택
- PPTX·발화 근거 선택
- 북마크 선택
- 퀴즈 연결 구간 선택
- 강사용 질문 핀 선택

## 9. 자막·전문용어·구조 요약

### 9.1 자막

- 현재 활성 게시 자막 사용
- 재생 시각에 맞는 구간 자동 강조
- 자막 표시·숨김
- 키워드 검색
- 검색 결과의 앞뒤 문맥 표시
- 결과 선택 시 해당 영상 시각으로 이동

### 9.2 전문용어

- 자막에서 게시된 전문용어 강조
- 선택 또는 호버 시 짧은 설명 표시
- 관련 PPTX 또는 발화 근거 확인

### 9.3 구조 요약

- 구간 제목
- 시작 시각
- 짧은 설명
- 선택 시 해당 시각으로 이동

수강생에게는 강사가 승인·게시한 현재 게시본만 표시하고 내부 AI 원본·후보·검수 초안을 노출하지 않는다.

## 10. 채팅 리플레이

- 라이브 당시 가명 유지
- 영상 `sessionMs`까지 발생한 메시지를 순서대로 표시
- 영상 탐색 시 해당 시점에 맞게 목록 재구성
- 질문으로 등록된 메시지에 질문 표시
- 삭제·제재된 메시지는 제외
- 표시 여부 켜기·끄기
- VOD에서 새 채팅 메시지 작성 불가

채팅 리플레이가 꺼져 있어도 재생과 다른 학습 기능은 유지한다.

## 11. 개인 AI Q&A

- 현재 재생 `sessionMs`를 질문 맥락으로 전달
- 교정 자막과 PPTX를 근거로 답변
- SSE 스트리밍 답변 표시
- 근거가 없으면 불충분 상태 표시
- 근거 선택 시 연결된 영상 시각으로 이동
- 라이브에서 작성한 같은 사용자의 개인 AI Q&A 기록 이어보기
- VOD에서 새로 작성한 질문도 같은 레슨 기록에 추가

질문 기록은 본인에게만 보인다. 강사에게는 라이브·VOD 개인 AI Q&A의 질문 원문과 시점만 익명 통계로 전달하며 사용자 식별자와 개인 답변 기록은 제공하지 않는다.

## 12. 북마크와 학습 진행

### 12.1 북마크

- 현재 시점에 북마크 추가
- 라이브에서 저장한 북마크도 동일한 시점에 표시
- 타임라인과 목록에서 북마크 선택
- 북마크 시점으로 이동
- 북마크 삭제

메모·색상·분류는 후속 기능이다.

### 12.2 진행률

- 마지막 재생 위치 자동 저장
- 일정 주기, 일시정지, 탭 이탈, 페이지 이탈 시 저장 시도
- 서버가 반환한 진행률과 완료 상태 표시
- 서버가 유효 시청 범위 또는 누적 시청량을 기준으로 90% 완료 판정
- 프론트는 단순히 가장 멀리 이동한 시각만으로 완료를 확정하지 않음
- 완료된 레슨도 다시 재생하고 북마크·퀴즈를 이용할 수 있음

저장 실패가 재생을 중단하지 않도록 하며, 실패 상태와 재시도 여부를 학습 상태 영역에 표시한다.

## 13. 퀴즈

### 13.1 수강생

- 영상과 분리된 `QuizPanel`에서 응시
- 퀴즈가 영상 재생을 강제로 중단하지 않음
- 강사가 게시한 현재 버전만 표시
- 제출 후 결정론 채점 결과 표시
- 연결된 구간이 있으면 해당 영상 시각으로 이동
- 응시 결과와 응시한 퀴즈 버전 확인
- 새 검수 버전이 게시되면 재응시 가능 상태 안내

재응시 가능 횟수와 정답·해설 공개 범위는 서버 정책을 따른다.

### 13.2 강사

- AI 원본 후보와 현재 게시 퀴즈 확인
- 문항·보기·정답·해설·연결 시점 검수
- 수정 결과를 새 버전으로 게시
- 이전 버전 응시 기록 보존 안내
- 새 버전 게시 전 영향 범위 확인

## 14. 강사용 질문 핀과 학습 요약

### 14.1 질문 핀

다음 질문을 같은 `sessionMs` 시간축에 집계한다.

- 질문으로 등록된 라이브 채팅
- 라이브 개인 AI Q&A
- VOD 개인 AI Q&A

강사 화면에는 다음을 제공한다.

- 전체 질문 개수
- 시간대별 질문 핀과 집중 정도
- 핀 선택 시 익명 질문 원문
- 해당 영상 시각·자막·근거로 이동

유사 질문 자동 묶음과 질문 밀도 히트맵은 후속 기능이다.

### 14.2 학습 요약

- 전체 수강생의 재생·완료 현황 집계
- 퀴즈 응시·완료 집계
- 질문이 집중된 구간

초기에는 집계 정보만 제공하고 개인별 상세 학습 분석은 범위에서 제외한다.

## 15. 강사 검수 흐름

1. 검수 영역 선택
2. AI 원본 후보·검수 초안·현재 게시본 비교
3. 영상 시점과 근거 확인
4. 수정본 저장
5. 게시 영향과 현재 버전 확인
6. 새 게시본 게시
7. 수강생 활성 게시본 교체 확인

- 검수 임시 저장과 게시를 분리
- 게시 중 중복 요청 방지
- 게시 실패 시 기존 게시본 유지
- 여러 영역을 개별 게시할 수 있도록 상태 분리
- 퀴즈는 새 버전 게시 시 기존 응시 결과가 유지됨을 안내

동시 검수 충돌과 되돌리기 정책은 API 설계 단계에서 확정한다.

## 16. 페이지 상태

### 16.1 초기 로딩

- 접근 권한·VOD 상태·재생 정보 확인
- 플레이어와 레슨 정보 skeleton 표시
- 권한 확인 전 검수 UI를 먼저 노출하지 않음

### 16.2 정상

- HLS 재생과 준비된 학습 기능 표시
- AI 영역별 게시·준비 상태 표시
- 역할에 맞는 수강생 또는 강사 패널 조합

### 16.3 녹화 자산 준비 중

- VOD 페이지 대신 레슨 상세의 처리 상태로 이동하거나 준비 안내 표시
- 자동 재확인 여부는 레슨 상세 명세에서 결정

### 16.4 부분 준비·부분 실패

- 자막·용어·챕터·퀴즈 중 준비된 영역만 활성화
- 실패 영역 가까이에 상태와 재시도 안내
- 영상 재생과 독립적인 AI 실패는 페이지 전체 오류로 처리하지 않음

### 16.5 재생 실패

- 재생 URL 만료와 HLS 로딩 실패를 구분
- URL 재발급 또는 플레이어 재시도
- 복구할 수 없으면 레슨 상세로 이동

### 16.6 빈 상태

- 채팅 없음: 정상 빈 상태
- 북마크 없음: 첫 북마크 안내
- 퀴즈 없음·준비 중: 각각 구분
- AI Q&A 기록 없음: 첫 질문 안내
- 질문 핀 없음: 강사용 정상 빈 상태

### 16.7 인증 만료·권한 변경

- 재생 URL과 학습 요청을 중단
- 로그인 또는 접근 불가 화면으로 이동
- 로그인 복귀 후 마지막 안전한 재생 위치 복원 시도

## 19. 반응형과 접근성

- 데스크톱은 영상과 보조 패널을 나란히 배치
- 좁은 화면은 자막·챕터·채팅·AI·퀴즈를 탭 또는 drawer로 전환
- 강사 검수 패널은 영상 시점을 확인할 수 있도록 플레이어를 완전히 가리지 않음
- 플레이어 제어와 타임라인 마커를 키보드로 조작 가능하게 제공
- 자막 검색 결과와 질문 핀 이동 후 변경된 영상 시각을 알림
- 후보·검수 중·게시 완료 상태를 색상 외 텍스트로 구분
- 채팅 리플레이와 자막 영역의 스크린 리더 갱신 빈도를 제한
