---
description: 변경분을 하네스 기준으로 리뷰
---

현재 변경분(`git diff`, 스테이지/미스테이지 모두)을 리뷰한다. 하네스 기준을 우선한다:

1. **계약 준수**: API 필드명이 camelCase인가? 상태코드가 `docs/CONTRACT.md §2` 규격과 맞는가? snake_case 응답이 새어들지 않았는가?
2. **완료 게이트**(`AGENTS.md §4`): 계약 걸린 변경에 테스트 증거가 있나? 기술 결정에 ADR이 있나?
3. **가짜 완료**: TODO / `test.skip` / `@Disabled` / 빈 스텁이 완료로 포함됐나?
4. 일반 품질: 버그·중복·명확성.

발견 사항을 심각도(blocker/major/minor)로 분류해 파일:라인과 함께 보고하라. 코드를 직접 고치지는 말고 제안만 하라.
