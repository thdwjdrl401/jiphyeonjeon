description: FE+BE 로컬 개발 서버 동시 실행
---

레포 루트에서 `npm run dev`를 실행해 프론트(8083, HMR)와 백엔드(8080, 핫리로드)를 동시에 띄운다.

- 최초 1회는 `npm run install:all`로 의존성 설치가 필요할 수 있다.
- `npm start`는 프론트를 빌드한 뒤 백엔드를 띄운다. 백엔드는 프론트 정적 파일을 서빙하지 않는다.
- 사전 요구사항·트러블슈팅은 `RUN.md` 참조. Java 21 `JAVA_HOME` 확인.

장시간 실행이므로 백그라운드로 띄우고, 기동 로그에서 두 포트가 열렸는지 확인해 보고하라.
